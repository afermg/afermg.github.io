* Recursive search and replace <2025-08-12 Tue>
It uses =ripgrep=, =xargs= and =GNU sed=. [[https://github.com/BurntSushi/ripgrep/blob/master/FAQ.md#search-and-replace][source]].

#+begin_src shell
rg old_pattern --files-with-matches | xargs sed -i 's/old_pattern/new_pattern/g'
#+end_src

* Github code review on existing code base <2024-11-26 Tue>

  Create an empty branch with one empty commit
  1. Create new branch =git checkout --orphan review-1-target=
  2. Reset =git reset .=
  3. Clean branch =git clean -df=
  4. Add empty commit =git commit --allow-empty -m 'Empty commit'=
     
  Rebase a branch to put this commit at the root
  5. Push to your fork =git push -u origin review-1-target=
  6. Move to branch to review =git checkout origin/main=
  7. Spin-off branch from here =git checkout -b review-1=
  8. Rebase to empty branch =git rebase -i review-1-target=, the empty commit must be at the start
  9. Push =git push -u origin review-1=

  That should make a pull request possible, providing the code review tooling.
  [[https://thib.me/recipe-code-reviews-for-existing-code-with-github][source]]
