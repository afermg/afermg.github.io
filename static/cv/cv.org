Computational biologist and scientific software engineer building infrastructure for large-scale image-based profiling and drug discovery. I design reproducible systems — from deep learning model deployment to statistical evaluation — that make terabyte-scale biological data tractable. I care deeply about software craft: modular architecture, principled API design, and thorough code review that keeps codebases maintainable as they scale. I adopt AI-assisted development tools where they accelerate work, while recognizing that the core engineering challenges — scoping the right problem, designing the right abstractions, and defining what success looks like — remain human responsibilities. At the Broad Institute, I architect pipelines processing 100+ TB datasets, build frameworks for training and deploying diverse deep learning models in reproducible environments, and develop open-source tools adopted across the image-based profiling community.

* Work Experience

** Postdoctoral Associate — Broad Institute of MIT and Harvard, Boston MA (2023–Present)

- *Led a GSK-funded collaboration** on high-content imaging, defining the project scope and designing an end-to-end automated microscopy processing framework built on [[https://github.com/afermg/aliby][ALIBY]] that eliminates manual steps from image acquisition through feature extraction and evaluation — establishing a path toward fully automated profiling

- *Architected GPU-accelerated scientific infrastructure* to process morphological profiles from >20 million images (~100 TB) in the JUMP Cell Painting dataset. Demonstrated that 98% lossy JPEG XL compression preserves biological signal, creating JUMP-lite — a curated 100 GB benchmark enabling research groups without specialized infrastructure to work with large-scale Cell Painting data (ECCV 2026, under review)

- *Built* [[https://github.com/afermg/nahual][Nahual]], a Nix-based framework for deploying and benchmarking heterogeneous deep learning models (MorphEM, OpenPhenom, SubCELL, DINOv2, Cellpose) via inter-process communication. Each model runs in an isolated, fully reproducible Nix environment, enabling systematic comparison of representation methods without dependency conflicts and supporting the benchmarking reported in the JUMP-lite analysis

- *Achieved a 200× speedup* of Average Precision computation in the [[https://github.com/cytomining/copairs][copairs]] framework by replacing the pair-matching logic with DuckDB-based relational joins, eliminating the prior bottleneck in sample-pair enumeration and enabling information retrieval evaluation at the full scale of the JUMP dataset (Kalinin et al., /Nature Communications/ 2025; [[https://github.com/cytomining/copairs/pull/79][PR #79]])

- *Created* [[https://github.com/afermg/cp_measure][cp_measure]], a modular Python library that extracts CellProfiler's core measurement engine into an API-first tool for programmatic feature extraction — freeing computational biologists from the GUI and enabling seamless integration with the scientific Python ecosystem. Adopted by labs across the image-based profiling community and integrated into spatial transcriptomics workflows via Squidpy (ICML 2025)

- *Built the [[https://broadinstitute.github.io/jump_hub][JUMP Hub]]*, a comprehensive ecosystem of tools, tutorials, and interactive interfaces for exploring the JUMP dataset. Designed lightweight data interfaces using Parquet files and Datasette Lite, enabling researchers to interactively query millions of rows of profiling data without specialized infrastructure. Created notebooks, interactive browsable tables, and programmatic access libraries

- *Pioneered a [[https://github.com/broadinstitute/monorepo][monorepo-based approach]]* for the Carpenter-Singh Lab's scientific software, unifying metadata translators, image retrieval tools, interactive data browsers, and feature extraction libraries under shared infrastructure — accelerating iteration and ensuring consistency across projects

- *Serves as an architectural steward* across the lab's open-source ecosystem, providing deep code review that shapes API design and long-term maintainability. Examples include restructuring a core statistical function in copairs ([[https://github.com/cytomining/copairs/pull/116][#116]]) to use composition over parameter accumulation, and driving a 9× reduction in code complexity for a data deposit pipeline by advocating for bash over overengineered Python ([[https://github.com/broadinstitute/monorepo/pull/95][#95]])

- *Led development of deep learning counterfactual methods* to interpret how chemical perturbations alter cellular morphology, enabling biologists to identify which visual phenotypes drive drug effects (work led through mentorship of an MSc intern)
